# AIGameLabo 必読

このプロジェクトはプレイヤー本人向けゲームを作る前に**複数のゲームの核を試遊比較するラボ**。`surumeneco/AIGameLabo` が対象リポジトリ。ゲームの正式企画・タイトルは未決定。Google Driveの以前の企画 `forGPT/FrontierBestiary/` は「野の法則」の先行資料であり、ラボ全体の正本ではない。

## 明示要件

- Phaser 3使用、スマートフォン縦画面、Webブラウザ、GitHub Pagesのみ。専用API/DB/サーバなし。セーブはLocalStorageなど端末内。
- 3ゲーム（生態誘導、戦術戦闘と遺物、鏡組立）を実際に遊び比較し、本人の面白さの評価を優先する。
- CAT-TDDは正規実行、同じスクリプト処理の再現実行、推論代替の順に適用。代替された作業はユーザーの指示により完了扱いとしてよいが、実行されていない検証を観測済みと呼ばない。
- Git反映は通常のdevelop/feature単位の分割コミットを原則とする。PR・マージ・CI・公開を区別する。

## 文書

- `比較実験.md`：比較する楽しさ、本人からの感想回収方法。
- `研究ノート.md`：学術・制作者一次資料と設計仮説。
- `作業・検証状況.md`：ローカルテスト実行とGitHub反映状況、未検証範囲。
- `CAT-TDD代替記録.md`：実装工程の段階・規範実行と代替の区別。
