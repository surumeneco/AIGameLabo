# 灯火の砦 — 行為の手応えを検証するプロトタイプ v0.1

状態：**プレイテスト用の実験企画（楽しさの実証ではない）**。『こもれび島の開拓記』のユーザーフィードバック「何をすればよいかは分かるが、そういうことができるんだ、で終わる」「ゲームだが遊びではない」を反証の起点とする。旧企画は `island.html` に退避し、検証結果を保持する。

## 試す核

プレイヤーの選択・操作精度・状況の変化が結果を左右する**短編アクション防衛**。中央の灯火を敵から3波守る。移動先を自分で決め、近づいて斬る、短い防御で敵を押し返す、波の合間に攻撃／機動力／防御／回復を選ぶ。何もせずに押し進められる順路や資源収集チェックリストを撤廃。

- 最初の15秒：操作で敵との距離と攻撃結果が変わる。
- 最初の1分：防衛の損傷と生存のリスク、3種類以上の敵の違いを体感する。
- その後：緑の遠距離敵は中心から離れて攻撃するため、接近の判断が必要。待機と積極的な迎撃で結末が分かれる。
- 波間：複数提示される強化から一つを選ぶ。異なるプレイスタイルを試す動機となるかを検証。
- 敗北時：もう一度試す余地を明示。勝利時：撃破数と自己ベストを保存し、再挑戦可能。

## 動作仕様

- スマホ縦画面、Phaser 3、ブラウザ、GitHub Pages配信。追加サーバーなし。
- 戦場タップ／ドラッグで移動先を指定、画面下ボタンで斬撃・盾。斬撃と盾は再使用待ちあり。
- 通常影（赤）、高速影（橙）、重装影（紫）、遠距離影（緑）の4種類。緑は第2波から登場し灯火を遠距離から狙う。
- 3波は12秒、15秒、18秒。ただし残敵がいれば片付くまで続く。
- 強化は8種類。毎回、まだ取っていない候補から3種類をランダム提示。戦況と相乗効果により選ぶ。
- ランダムはシード付き。ローカルベスト以外の実行状態は保存しない（短編の最初から遊び直す）。
