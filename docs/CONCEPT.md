# 新企画候補：こもれび島の開拓記（v0.1 / 探索的試作）

## 目的
既存3作の「目標・操作が理解できない、説明が不正確、記号パズルの正解探しだけ」という失敗を検証するため、**自分の操作で具体的に景色が変化する**短い開拓ゲームを作る。初期ゲーム性を証明するものではない。

## プレイヤーへの約束（30秒）
「木を3本集めて橋を架ける。向こう岸で花2輪を手に入れ庭を作る。最後に石2個を集めて灯台を直す」。対象をタップすると主人公が向かい、資材が増える。ボタンは実行可能になった時だけ表示。やり直し・詰みはない。

## 操作方法
- キャンバス上の光っている資源を**直接タップ**。移動と採集を同じ操作にする。
- 必要数が揃った時のみ「橋を架ける」「庭を作る」「灯台を灯す」ボタンが現れる。
- 庭には青系・夕焼け系の色選択があり、自分の決定が描画結果に影響する。
- 画面上部に現在の目的・資材数、下に**次にすること**を常時表示。ヘルプは再表示可能。
- 進行状態はLocalStorageで保存。はじめから遊ぶで消去可能。

## 体験する変化
1. 橋がかかる→遠くの島と新しい資源が見える。
2. 庭を選ぶ→地面に選択した色の花畑が増える。
3. 灯台を直す→暗い灯台に光と回転する光芒が出る。
4. クリア後は好きな花の色を選び、草地をタップして最大30輪の花を自由に飾れる。

## 品質ゲート
- P0：初回の指示に正しい具体対象と操作を書く。無効操作は状態を変更せず理由を返す。
- P0：操作対象に十分なタップ領域があり、タップ→資材増加→UI・画面変化が連続する。
- P0：3工程は最初から最後まで到達可能。分岐（庭の色）が画面に反映。
- P1：実ブラウザでモバイル幅を用いたクリック・リロードを検証。Actionsのビルド成功と公開成功は独立。
- G3：本人の「もう一度遊びたい」は別途確認。単なるクリック収集でも退屈なら失敗として扱う。

## スコープ外
ランダム生成、戦闘、複雑な工作、資源枯渇・敗北。将来の趣味ゲームとして成立するには、この試作以外の遊びと選択肢が必要。今は理解可能性と操作可能性を実測する。
