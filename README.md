# AIGameLabo

**Phaser 3 × スマートフォン縦画面**で3種類のゲーム体験を比較する、実験用プロトタイプ集です。正式なゲーム企画はまだ決まっていません。

## プレイ

GitHub Pagesが有効化されていれば、公開先はリポジトリの **Settings → Pages** に表示されます。GitHub Actionsによるデプロイ設定が必要です。

1. **野の法則** — 光に集まる虫と、それを追う獣の動きを利用して任務を解く。
2. **遺物の迷宮** — 攻撃予告のある小盤面で戦い、勝利するたび遺物を選ぶ。
3. **機構工房** — 光源・鏡・受光器をつなぐように鏡を組み立てる。

試作品には未調整のステージが含まれます。目的は「完成度の評価」ではなく、**どの判断が楽しかったか／面倒だったか**を発見することです。

## 開発

```sh
npm install
npm run dev
npm test
npm run build
```

`npm run build` は `dist/` に静的サイトを作成します。GitHub Pages用のサブパスでも動くよう、アセット参照は相対パスです。

## データの扱い

プレイ状態と試遊メモは端末の `localStorage` に保存されます。「結果をJSON保存」でメモを端末にエクスポートできます。サーバーへの送信はしません。ブラウザのサイトデータを削除すると保存内容は消えます。
